# JEU DES ALLUMETTES

## Présentation

Jeu des allumettes réalisé dans le cadre d’un exercice JavaScript à ADA Tech School.
Le but est de retirer des allumettes à tour de rôle jusqu’à ce qu’il n’en reste plus.

## Règles du jeu

* La partie commence avec 50 allumettes.
* Chaque joueur peut retirer entre 1 et 6 allumettes.
* Le joueur qui retire la dernière allumette remporte la partie.

## Modes de jeu

* 🤖 Jouer contre l’ordinateur.
* 👥 Jouer à plusieurs.
##Technologies utilisées
* HTML5
* CSS3
* JavaScript

## Lancer le jeu

Télécharger ou cloner le dépôt, puis ouvrir jeu-allumettes.html dans un navigateur web.
